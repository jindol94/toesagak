개인정보처리방침

시행일: 2026년 7월 14일

「회사에서 살아남기」(이하 "앱")는 이용자의 개인정보를 소중하게 생각하며, 다음과 같이 처리방침을 안내합니다.

1. 수집하는 개인정보

앱은 어떠한 개인정보도 수집하지 않습니다. 이용자가 입력하는 모든 정보(연봉, 입사일, 생활비, 출생연도 등)는 이용자 기기의 저장 공간(localStorage)에만 저장되며, 외부 서버로 전송되지 않습니다.

2. 서버 및 외부 전송

  • 앱은 자체 서버를 운영하지 않으며, 입력 데이터를 어디로도 전송하지 않습니다.
  • 제3자 분석 도구, 광고 SDK, 추적 기술을 사용하지 않습니다.

3. 데이터 보관 및 삭제

  • 모든 데이터는 이용자 기기에만 존재하며, 앱 내 "계정 삭제" 기능으로 즉시 완전 삭제할 수 있습니다.
  • 앱을 삭제하면 저장된 모든 데이터가 함께 삭제됩니다.

4. 알림

월급날·연차 소멸 알림은 이용자가 직접 켠 경우에만 기기 내에서 예약되며, 알림 내용은 외부로 전송되지 않습니다. 알림은 언제든 앱 또는 기기 설정에서 끌 수 있습니다.

5. 계산 결과의 성격

앱이 제공하는 모든 계산(퇴직금, 실수령액, 실업급여 등)은 참고용 추정치이며 법적 효력이 없습니다.
